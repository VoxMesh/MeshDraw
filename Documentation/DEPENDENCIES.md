# Зависимости и компоненты

Python использует стандартную библиотеку. Тесты JavaScript используют встроенные модули Node.js. Страница использует API браузера, Web Crypto, BigInt и системные шрифты. SVG-знак встроен в HTML. Отдельные файлы шрифтов, пакеты npm, Python wheels и исполняемые файлы не поставляются.

Иллюстрация антенны [AX-865-14Y с логотипом 73lab](../docs/assets/ax-865-14y.webp) предоставлена владельцем для страницы конкурса. На сайте используется оптимизированный WebP без метаданных. Лицензия MIT проекта на иллюстрацию не распространяется.

Вычислитель, проверка архивного пакета и интерфейс относятся к MeshDraw. Python-модули архивного профиля выполняют локальную проверку. Тестовые наборы содержат искусственные наблюдения и билеты.

Собственный код MeshDraw распространяется по [лицензии MIT](../LICENSE). Условия использования установленных Python, Node.js и браузера определяются их поставщиками.
